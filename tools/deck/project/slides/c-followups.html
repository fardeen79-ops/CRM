Before the file · Follow-ups

Tomorrow's calls are on the sales person's screen today, with the number one tap away

A date and a time on every lead

Set when the lead is entered, or in one tap on the list. The day before, the lead appears on the dashboard as a task for tomorrow; on the day it moves to today; missed, it turns red as overdue.

From task to call to file

Each task carries the customer's number: a tap asks "Call?" and opens the phone's dialler. A Convert link starts the file with the lead's details already filled in. A lead sheet can be photographed to enter the lead in the first place.

Why it matters

Promised call-backs stop depending on memory. The team leader's dashboard shows the same tasks for the whole team, so a missed day is visible before the customer is lost.
