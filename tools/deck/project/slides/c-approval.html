Control 3 · Manager approval

No reason given, no verification until a manager decides

The approval queue

A card file sent below the salary minimum without a reason goes to an Awaiting approval queue for the team leader, ASM or sales manager. Processors cannot pick it up.

The decision

The manager records the reason (deviation or promotion) and releases the file to verification, or returns it to the sales person with a note. Their name and time are stamped on the file.

Why it matters

Exceptions are decided by a named manager before the file reaches the bank, not discovered in the bank's audit months later.
