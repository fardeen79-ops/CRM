Control 1 · Sourcing

Every file starts complete and correctly identified

What the screen does

The sales person enters the salutation and names, the mobile number and the product; details can be dictated. Region, products and the customer's salary bank are chosen from lists. No Emirates ID or passport number is ever typed or stored.

Why it matters

A lead can be photographed and converted into the file with the details already filled, so the file matches what the customer gave. Keeping ID numbers out of the system removes the data the business least wants to hold.

What it stops

Incomplete files. Required fields depend on the product, so a card file cannot be sent without a card, salary and fee type, and a loan file cannot be sent without its amount, rate and tenure.
