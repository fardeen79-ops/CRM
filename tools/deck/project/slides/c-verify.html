Control 5 · Verification

A second person confirms every detail with the customer

What the processor does

Picks the file from the region's queue, calls the customer, reveals the phone number only to dial, and confirms the salary, employer, product and amounts. Each call is logged with its outcome.

When something is wrong

No answer: a call-back is scheduled and chased. A mismatch: the file goes back to the sales person with a note, is corrected, and returns for re-verification.

The outcome

Completed, pending or rejected, with notes. Nothing reaches the bank unverified, and the verification report shows each processor's calls, call-backs and turnaround.
